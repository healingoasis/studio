# Healing Oasis Studio

Hi Daniel. This is your idea studio. You talk, Claude does the technical work, and
everything gets saved and backed up automatically so Dan can see it and take things live.

## How to use it (every time)

1. Open the **Terminal** app.
2. Type `cd studio` and press Enter.
3. Type `claude` and press Enter.
4. Talk. That is the whole workflow.

Things you can say:

- "I have an idea..." (or type `/idea`) and describe it. Claude writes it up and saves it.
- `/status` for a recap of every idea and where it stands.
- `/prototype` to turn an idea into something you can actually click around in.
- `/ask-dan` when something needs Dan (going live, passwords, store changes).

## The rules of the house

- **Nothing goes live without your clear yes**, and the big stuff goes through Dan.
- Prototypes are sandboxes. Play freely, nothing here can break the store or the website.
- Every session is saved and backed up. You cannot lose work and you cannot break this
  folder in any way Dan can't undo, so experiment.

## First-time setup (once, with Dan on a call)

1. Install Claude Code: https://claude.com/claude-code
2. Get this folder onto your computer (Dan will help clone it).
3. Dan sends you one settings file (`.env.local`) to drop into this folder. It holds
   the keys that connect Claude to the store and other tools. Never share that file.
