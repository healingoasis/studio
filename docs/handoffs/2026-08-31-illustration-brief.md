## Why this exists

The Learn page carries an interactive Henneke body condition tool. The photograph of Captain
shows **where** the six palpation sites are. What is still missing is **what each of the nine
scores looks like**, because no single photograph can be nine horses.

Claude drew that horse five times and it never reached the standard Daniel wants. Hand-authored
vector anatomy in code has a ceiling and this is it. The honest fix is a real illustrator or real
photographs. This is the brief for the illustrator route.

## What is needed

**Nine lateral-view plates of the same horse**, one at each Henneke score, 1 through 9.

- **True lateral.** Square side-on, standing square, level ground, camera at mid-body height.
- **The same animal throughout.** Same breed type, markings, mane and tail, stance. Only
  condition changes between plates. This is the whole point: a viewer must be able to attribute
  every difference to body condition and nothing else.
- **A stock-horse type** (quarter horse), matching the animals this rescue actually takes in.
- What must visibly change across the nine: crest of the neck, withers, behind the shoulder,
  the ribs, the loin, the tailhead, the flank, and the belly line.
- Score 1 must read as a veterinary emergency. Score 9 must read as obese, not merely round.

## Style

Look at the existing site before starting — cold lavender ground, one violet accent, restrained.
The plates should read as **a veterinary teaching reference, not a children's book**: confident
line, controlled tone, no cuteness, no scenery, no ground shadow.

Line art or flat two-tone both work. What matters is that it looks like it belongs in a textbook.

## Files

- **SVG**, one file per score, same viewBox and same registration across all nine, so they can be
  cross-faded and overlaid.
- Paths grouped and named by region (topline, underline, crest, neck, barrel, hindquarter, legs,
  head, mane, tail) so the site can address them.
- No embedded rasters. No text in the artwork.

## One extra thing worth asking for

The site currently overlays a dashed outline of the **ideal 5** on top of whichever score is
showing, so a viewer sees exactly how far the topline has dropped or the belly has filled. If
all nine plates share registration this works automatically — please keep that in mind when
setting them up.

## Rights

The rescue needs to own the artwork outright, including the right to print it on a barn-wall
chart and hand it to students. Please quote for a full buyout, not a licence.

## What the rescue can supply

Reference photographs of Red and Captain, both recovered, and the case notes: Red came in
250 lb underweight, Captain around 500 lb and took well over a year.
