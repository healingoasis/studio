# plans/

Intended work, written **before** building. A plan is the source of truth for
*what* to build and *why*, agreed with the human before code is written.

Write a plan here for any non-trivial task. Read the matching plan before
starting work. Name by date + slug: `2026-05-29-auth-flow.md`.

A plan typically covers: the goal, the scope (in and out), the approach, the
files/packages touched, and open questions for the human.
