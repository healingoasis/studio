# notes/

Running notes captured **during** a build. The place for non-obvious decisions —
tradeoffs taken, workarounds, deviations from the plan and why.

Keep entries terse; this is a log, not documentation. The goal is that a fresh
session (or a parallel worktree) can read the reasoning instead of re-deriving
it. Match the slug of the related plan: `2026-05-29-auth-flow.md`.
